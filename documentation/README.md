- `SECURITY.md` — security controls and remaining limitations
- `PERFORMANCE.md` — implemented optimizations and measurement plan
- `AI_ML_DOCUMENTATION.md` — model behavior, evaluation and limitations
- `API_DOCUMENTATION.md` — API contracts
- `DATABASE_DOCUMENTATION.md` — models, indexes and migration notes
- `INSTALLATION.md` — local setup
- `DEPLOYMENT.md` — Docker Compose and production caveats
- `TESTING.md` — test commands and staging test plan
- `ENVIRONMENT_CONFIGURATION.md` — configuration reference
- `CHANGELOG.md` — update summary
